# Sirdaryo 360

Sirdaryo viloyati uchun interaktiv turistik web-sayt.

## Fayllar

- `index.html` — asosiy sahifa, 360° panorama, interaktiv xarita, audio gid, ob-havo va turistik qulayliklar.
- `mehmonxonalar.html` — Sirdaryo viloyatidagi mehmonxonalar katalogi.
- `ovqatlanish.html` — restoran, kafe va boshqa ovqatlanish joylari katalogi.

## GitHub Pages

1. GitHub'da yangi repository yarating, masalan `Sirdaryo360`.
2. Ushbu papkadagi barcha fayllarni repository root'iga yuklang.
3. **Settings → Pages** bo‘limiga kiring.
4. **Deploy from a branch** ni tanlang.
5. Branch sifatida `main`, folder sifatida `/ (root)` ni tanlang.
6. Save bosing.
7. GitHub Pages sizga sayt manzilini beradi.

`index.html` root papkada turgani uchun asosiy sahifa avtomatik ochiladi. Ichki sahifalar nisbiy yo‘l bilan ulangan:

- `mehmonxonalar.html`
- `ovqatlanish.html`

## Muhim

Saytning ayrim funksiyalari internetga bog‘liq: xarita kutubxonalari, 360° panorama kutubxonasi, Google Maps havolalari, tashqi rasmlar va ob-havo ma'lumotlari.
